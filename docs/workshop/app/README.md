# The workshop doc's source

The master workshop doc (a claude.ai artifact with a shared database) is put together from these files by `assemble.py <sha> <install text>`
into one page; its 3D data (`live/`, `real/`) and sounds (`snd/`) are built from Noah's own install by `tools/preview/export_live.py`,
`tools/realpreview.py`, `tools/zombiepreview.py`, `tools/playerpreview.py` and `tools/soundopts.py`, and are never committed.
